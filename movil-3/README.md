# README - Aplicación Móvil con React Native y Expo

## 📱 app veterinaria ciudad canina

aplicacion movil para la veterinarai ciudad canina que consume las apis del backend web

## 🚀 Requisitos previos

tener:
- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/) instalado globalmente
  
  npm install -g expo-cli
 ## instalar dependencias
  npm install

## Para iniciar la aplicación en modo desarrollo en la aplicacion Expo Go:
npm start
Escanear el código QR con la app Expo Go (disponible en App Store y Play Store)
